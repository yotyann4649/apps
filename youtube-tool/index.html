三星鑑 動画アップローダー

このページは、三星鑑 動画アップローダーの説明です。

三星鑑 動画アップローダーは、運営者が自分の YouTube チャンネルへ動画を上げるための、個人用の道具です。

運営者のパソコンの中で動き、YouTube Data API（YouTube API サービス）を使って、

動画を「非公開」で自分のチャンネルへ上げます。公開するかどうかは、運営者が YouTube Studio で決めます。

この道具を使うのは運営者1人だけです。ほかの方が登録したり、ログインしたりする機能はありません。
