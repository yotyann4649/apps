三星鑑 動画アップローダー

このページは、三星鑑 動画アップローダーの説明です。

三星鑑 動画アップローダーは、運営者が自分の YouTube チャンネルへ動画を上げ、上げた動画の様子を確かめるための、個人用の道具です。

運営者のパソコンの中で動き、YouTube Data API と YouTube Analytics API（YouTube API サービス）を使って、

動画を「非公開」で自分のチャンネルへ上げ、動画の公開の範囲や再生の数を読みます。

運営者が動画ごとに確かめて認めた回は、公開の日時を付けて上げ、その日時に YouTube が公開へ切り替えます。公開の範囲は、運営者が YouTube Studio でいつでも変えられます。

この道具を使うのは運営者1人だけです。ほかの方が登録したり、ログインしたりする機能はありません。
