三星鑑 動画アップローダー プライバシーポリシー

制定日：2026年10月22日

1. この道具について

三星鑑 動画アップローダー（以下「本ツール」）は、運営者が自分の YouTube チャンネルへ動画を上げるための個人用の道具です。

本ツールは YouTube API サービスを使っています。

2. 本ツールが使う Google アカウントの権限

本ツールが Google に求める権限は、次の1つだけです。

・https://www.googleapis.com/auth/youtube.upload（YouTube へ動画を上げる）

本ツールは、この権限で運営者のチャンネルへ動画を「非公開」で上げます。

チャンネルの情報・動画の一覧・視聴者の情報・コメントなどを読む権限は求めていません。

3. 本ツールが扱う情報

本ツールが扱うのは、次のものだけです。

・運営者が上げる動画のファイルと、その題名・説明文

・Google から受け取る「許可の鍵」（アクセストークンとリフレッシュトークン）

これらは運営者のパソコンの中にだけ保存します。本ツールは、運営者以外の方の個人情報を集めません。

4. 情報の使い方と、人に渡すこと

許可の鍵は、動画を YouTube へ上げるためだけに使います。

動画と題名・説明文は、YouTube へ上げるためだけに Google（YouTube）へ送ります。

それ以外の第三者へ、情報を渡したり売ったりすることはありません。

5. 広告・クッキー

本ツールは、広告を出しません。第三者に広告やコンテンツを出させることもありません。

本ツールは、利用者の端末やブラウザにクッキーなどを置いたり読んだりしません。

6. 情報の消し方と、許可の取り消し

運営者は、パソコンの中の許可の鍵のファイルを消すことで、保存した情報を消せます。

あわせて、Google のセキュリティ設定のページから、本ツールの許可をいつでも取り消せます。

https://security.google.com/settings/security/permissions

7. Google のプライバシーポリシー

YouTube API サービスでの情報の扱いには、Google のプライバシーポリシーも適用されます。

http://www.google.com/policies/privacy
