三星鑑 動画アップローダー プライバシーポリシー

制定日：2026年10月22日（2026年11月7日に改定）

1. この道具について

三星鑑 動画アップローダー（以下「本ツール」）は、運営者が自分の YouTube チャンネルへ動画を上げ、上げた動画の様子を確かめるための個人用の道具です。

本ツールは YouTube API サービス（YouTube Data API と YouTube Analytics API）を使っています。運営者以外の方のアカウントには使いません。

2. 本ツールが使う Google アカウントの権限

本ツールが Google に求める権限は、次の3つです。

・https://www.googleapis.com/auth/youtube.upload（YouTube へ動画を上げる）

・https://www.googleapis.com/auth/youtube.readonly（運営者のチャンネルと動画の様子を読む。読むだけで、上げる・消す・書き換えることはできません）

・https://www.googleapis.com/auth/drive.file（運営者の Google ドライブへ、本ツールが作ったファイルを置く。ドライブのほかのファイルは見えません）

動画は「非公開」で上げます。運営者が動画ごとに確かめて認めた回は、公開の日時を付けて上げ、その日時に YouTube が公開へ切り替えます。公開の日時を付けない動画は、非公開のままです。公開の範囲は、運営者が YouTube Studio でいつでも変えられます。

本ツールが読むのは、次のことだけです。

・運営者のチャンネルの番号・登録者数・総再生数・動画の一覧

・運営者の動画の番号・題名・説明文などの基本の情報・公開の範囲・公開の日時・処理の結果

・運営者の動画の数（再生・いいね・コメントの件数、平均の視聴の長さと割合）

コメントの本文と、視聴者の方の情報は読みません。

3. 本ツールが扱う情報

本ツールが扱うのは、次のものだけです。

・運営者が上げる動画のファイルと、その題名・説明文・タグ

・上の2で読む情報（数は動画ごとの合計や平均であり、どなたが見たかは分かりません）

・Google から受け取る「許可の鍵」（アクセストークンとリフレッシュトークン）

許可の鍵は、運営者のパソコンの中にだけ保存します。読んだ情報は、運営者のパソコンの中と、その控えを置く運営者の Google ドライブに保存します。本ツールは、運営者以外の方の個人情報を集めません。

4. 情報の使い方と、人に渡すこと

許可の鍵は、動画を YouTube へ上げること、上の2のことを読むこと、Google ドライブへファイルを置くことのためだけに使います。

読んだ情報は、次のためだけに使います。運営者が動画を見直すこと、動画が出たか・公開の日時が入っているかを確かめること、新しいコメントが来たと知ること、パソコンが壊れたときに備えて控えを置くこと。

運営者は、この見直しのために、読んだ情報を運営者の指示で AI の道具（Anthropic の Claude）に読ませます。許可の鍵は読ませません。

運営者は、この控えのために、読んだ情報と、動画・題名・説明文を、運営者の指示で、運営者の Google ドライブ（Google のサービス）に置きます。許可の鍵は置きません。

動画と題名・説明文・タグは、YouTube へ上げるために Google（YouTube）へ送ります。

運営者は、上げた動画と同じ動画を、別の道具で Instagram へ出すことがあります。その扱いは、その道具のポリシーに書いています。

ここに書いた Anthropic と Google のほかの第三者へ、本ツールの情報を渡したり売ったりすることはありません。

5. 広告・クッキー

本ツールは、広告を出しません。第三者に広告やコンテンツを出させることもありません。

本ツールは、利用者の端末やブラウザにクッキーなどを置いたり読んだりしません。

6. 情報の消し方と、許可の取り消し

運営者は、パソコンの中の許可の鍵と記録のファイル（読んだ情報を書き写した作業の記録を含みます）、Google ドライブの控え（ゴミ箱の中を含みます）を消すことで、保存した情報を消せます。

これを消しても、YouTube に置かれた動画や情報は消えません。YouTube の側を消すには、YouTube Studio などから消します。

あわせて、Google のセキュリティ設定のページから、本ツールの許可をいつでも取り消せます。

https://security.google.com/settings/security/permissions

許可を取り消したときは、本ツールが読んだ情報も7日以内に消します。

本ツールが扱った情報を消してほしいときは、8の宛先へお知らせください。確かめたうえで、7日以内に消します。

7. Google のプライバシーポリシー

YouTube API サービスでの情報の扱いには、Google のプライバシーポリシーも適用されます。

http://www.google.com/policies/privacy
