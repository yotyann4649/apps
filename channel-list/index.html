三星鑑 動画の一覧の道具 プライバシーポリシーと利用規約

制定日：2026年11月8日

1. この道具について

三星鑑 動画の一覧の道具（以下「本ツール」）は、運営者が仕事の学びのために選んだ YouTube チャンネルの動画の一覧を作る道具です。運営者のパソコンの中で動き、運営者だけが使います。

本ツールは YouTube API サービス（YouTube Data API）を使っています。

本ツールは、どなたの Google アカウントの許可も求めません。API キーで、公開されている情報だけを読みます。

2. 本ツールが読むもの

・運営者が選んだチャンネルの番号・名前・動画の本数・動画の一覧（同じ問い合わせで返る登録者数などは、使わず、保存しません）

・その動画の番号・題名・説明文などの基本の情報・長さ・公開の状態

コメントの本文と、視聴者の方の情報は読みません。動画と音声のファイルは、本ツールでは読みません。

3. 読んだ情報の使い方と、人に渡すこと

読んだ情報は、次のために使います。どの動画を文字に起こすかを決めて順番を付けること、動画がまだ在るかを確かめること。

運営者は、動画の番号（URL）を文字起こしのサービス（TurboScribe）へ渡して動画を文字に起こし、仕事の学びの資料にします。

運営者は、順番を決めるために、題名を運営者の指示で AI の道具（Anthropic の Claude）に読ませることがあります。API キーは読ませません。

運営者は、パソコンが壊れたときに備えて、読んだ情報の控えを運営者の Google ドライブ（Google のサービス）に置きます。API キーは置きません。

ここに書いた TurboScribe、Anthropic、Google のほかの第三者へ、本ツールの情報を渡したり売ったりすることはありません。

4. 保存と消し方

本ツールが読んだ情報は、運営者のパソコンの中と、上の控えに保存します。

本ツールが持つ題名は、30日を超える前に YouTube から読み直すか、消します。YouTube から返らなくなった動画の題名は消します。

文字に起こした原稿とその名前は、本ツールの外にある運営者の資料として持ちます。

運営者は、保存したファイルと控え（ゴミ箱の中を含みます）を消すことで、本ツールの情報を消せます。これを消しても、YouTube に置かれた動画や情報は消えません。YouTube の側を消すには、YouTube Studio などから消します。

本ツールが扱った情報を消してほしいときは、7の宛先へお知らせください。確かめたうえで、7日以内に消します。

5. 広告・クッキー

本ツールは、広告を出しません。第三者に広告やコンテンツを出させることもありません。

本ツールは、利用者の端末やブラウザにクッキーなどを置いたり読んだりしません。

6. Google のプライバシーポリシーと YouTube 利用規約

YouTube API サービスでの情報の扱いには、Google のプライバシーポリシーも適用されます。

http://www.google.com/policies/privacy

本ツールを使う方は、YouTube 利用規約に同意したものとします。
