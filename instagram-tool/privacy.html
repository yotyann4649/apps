biwako-post プライバシーポリシー

制定日：2026年11月7日（同日、4の置き場の文を改定）

1. この道具について

biwako-post（以下「本ツール」）は、運営者が自分の Instagram アカウントへリール動画を投稿するための個人用の道具です。

本ツールは Meta の Instagram API を使っています。運営者以外の方のアカウントには使いません。

2. 本ツールが Instagram で行うこと

本ツールが行うのは、次のことだけです。

・運営者のアカウントへリール動画を投稿する

・運営者のアカウントの番号・名前・フォロワー数・フォロー数・投稿数を読む

・運営者の投稿の番号・種類・説明文・日時・投稿の住所を読む

・運営者の投稿の数（再生・リーチ・平均視聴時間・いいね・保存・シェア・コメントの件数）を読む

コメントの本文、ダイレクトメッセージ、ほかの方のアカウントの情報は読みません。

3. 本ツールが扱う情報

本ツールが扱うのは、次のものだけです。

・運営者が投稿する動画と表紙の画像、その説明文

・上の2で読む情報（数は投稿ごとの合計であり、どなたが見たかは分かりません）

・Instagram から受け取る「許可の鍵」（アクセストークン）

許可の鍵は、運営者のパソコンの中にだけ保存します。読んだ情報は、運営者のパソコンの中と、その控えを置く運営者の Google ドライブに保存します。本ツールは、運営者以外の方の個人情報を集めません。

4. 情報の使い方と、人に渡すこと

読んだ情報は、次のためだけに使います。運営者が投稿を見直すこと、投稿が出たかを確かめること、新しいコメントが来たと知ること、パソコンが壊れたときに備えて控えを置くこと。

運営者は、この見直しのために、読んだ情報を運営者の指示で AI の道具（Anthropic の Claude）に読ませます。許可の鍵は読ませません。

運営者は、この控えのために、読んだ情報と、動画・表紙の画像・説明文を、運営者の指示で、運営者の Google ドライブ（Google のサービス）に置きます。許可の鍵は置きません。

動画・表紙の画像・説明文は、投稿のために Meta（Instagram）へ送ります。

動画と表紙の画像は、Instagram が取り込めるよう、投稿の準備の間だけ GitHub の公開の置き場へ置き、取り込みが済むと消します。消したあとも、しばらくは取れる場合があります。2026年11月7日より前に置いた分は、置き場の更新の履歴に残り、そこから取れる場合があります。

ここに書いた Anthropic・Google・Meta・GitHub のほかの第三者へ、情報を渡したり売ったりすることはありません。

5. 広告・クッキー

本ツールは、広告を出しません。第三者に広告やコンテンツを出させることもありません。

本ツールは、利用者の端末やブラウザにクッキーなどを置いたり読んだりしません。

6. 情報の消し方と、許可の取り消し

運営者は、パソコンの中の許可の鍵と記録のファイル（読んだ情報を書き写した作業の記録を含みます）、Google ドライブの控え（ゴミ箱の中を含みます）を消すことで、保存した情報を消せます。

あわせて、Instagram の設定にある、アプリとウェブサイトの許可の画面から、本ツールの許可をいつでも取り消せます。

本ツールが扱った情報を消してほしいときは、8の宛先へお知らせください。確かめたうえで、速やかに消します。

7. Instagram のプライバシーポリシー

Instagram での情報の扱いには、Instagram のプライバシーポリシーも適用されます。

https://privacycenter.instagram.com/policy
