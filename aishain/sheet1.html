AI社員の部屋で使っている紙　1枚目／3枚

判断表の形

この紙が止めること

AIの報告に「ご判断ください」と書いてあると、毎回ぜんぶ読まないと、本当に決めることがあるのか分かりません。
数えてみたら、私に判断を求める見出しが立っていた18件のうち、15件は中身が「ありません」でした。

決まり（AIに渡す文）

報告の1行目は、必ずこの形で始めてください。
  判断：0件
  判断：1件（〇〇を選んでほしい）

判断が1件以上あるときは、報告の中に下の表を1つだけ置いてください。
判断が0件なら、表は置かないでください。

表の形（写して使ってください）

| 決めること | （1行で。何を選ぶのか） |
|---|---|
| なぜ今 | （決めないと何が止まるか。1〜2行） |
| A | （選んだら、何が起きるか） |
| B | （同じ） |
| C | （3つまで。無ければ消す） |
| AIの推し | （A/B/C のどれか）―― 推しは材料です。決めるのは私です |
| 期限 | （いつまでに決めれば間に合うか。無ければ「なし」） |

書いてもらった例（中身は置き換えてあります）

判断：1件（毎週の短い手紙に、アンケートの入口を置くか）

| 決めること | 毎週の短い手紙の最後に、3問アンケートへの入口を置くか |
|---|---|
| なぜ今 | 置くと手紙が「広告のメール」の側に入るおそれがあり、送り主の表示の決まりが増える |
| A | 手紙には置かない。入口は登録のあとの画面だけ |
| B | 値段の数字を外して置く（広告に当たらないとは言い切れない） |
| C | 送り主の表示を決める日まで待つ |
| AIの推し | A ―― 推しは材料です。決めるのは私です |
| 期限 | 次の月曜の送信まで |

使ってみて分かったこと

  • 1行目だけ見て「0件」なら後回しにできます。読む量が大きく減りました
  • 選択肢は3つまでにしています。4つ以上あるときは、たいてい問いが2つ混ざっています
  • 「推し」は書かせますが、必ず「材料です」と添えさせます。推しをそのまま押す癖がつかないように

3枚とも、写して使える形にした紙です。私の部屋で動いているプログラムそのものではないので、お使いの環境でそのまま動くことはお約束できません。
